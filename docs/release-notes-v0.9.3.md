# Observer v0.9.3 发布说明

## 搜索焦点修复

- 修复可搜索下拉框输入首字符后失去焦点的问题，适用于请求页模型、客户端 Key、
  提供商、账户等使用共享 Select 的筛选项。
- 原因是实时过滤移除了原来选中的选项（例如“全部模型”），Radix 随后自动将焦点
  转到列表容器。现在仅在可搜索列表容器自身获得焦点时交回搜索框，
  不使用定时器或每次渲染强制抢焦点，不干扰明确聚焦的选项。
- 连续输入及远端 facet 选项更新后可以继续搜索；方向键、Enter 选择和 Escape
  关闭行为保留，筛选值与查询应用方式不变。
- 增加真实键盘回归，覆盖首字符、连续输入、异步选项补充、方向键返回搜索及选择。
  不用一次性设置输入值代替逐字输入；内嵌前端资源已同步构建。

## 兼容与升级

这是 v0.9.2 的前端交互修正补丁，不改认证、模型权限、额度、并发、用量细分、
定价、历史账单或内容采集规则。CPA 原生凭据与 Observer 继续非独占共存。
没有 CPA 核心修改或 Go/npm 依赖升级。

沿用 schema2、`observer_features=2` 和原数据库路径，不新增迁移。
**客户端 Key 明文仍保存在管理数据库中**；升级或回退前请安排停流并做一致备份，
详细要求见 [v0.9.0 发布说明](release-notes-v0.9.0.md)。
请求头采集和自定义 provider 用量恢复的限制见
[v0.9.2 发布说明](release-notes-v0.9.2.md)。

SDK 仍锁定 CPA v8.0.30，最低插件 schema 6。
发行平台仍为 Linux amd64、Linux arm64、macOS arm64。
下载后核对 `checksums.txt` 和归档内 `metadata.json`。
既有标签和公开资产不覆盖；发布不部署到生产、不修改生产配置或数据库。
