# Observer v0.8.0 发布说明

## 本版变化

- **修复原生认证共存**：不再声明独占认证。CPA 原生 Key 继续由宿主管理，
  Observer 只管明确支持、由专属 Observer Key 认证的生成请求。目录/count
  不占额度、并发槽或内容采集；count 仍检查模型授权。
- 三页采用全宽布局、统一可搜索控件和 CPA 主题；仅请求日志定时刷新。
  刷新保留现有行、滚动和焦点，阅读/编辑时暂停；失败保留旧数据并退避。
- 请求页提供 UTC 日期筛选、明确查询、六项概览、趋势、详细 Token/缓存/时延/
  TTFT/费用，以及模型、Key、账户、提供商分组。完整样本与未知数据分别展示，
  不虚构历史细分或平均 TPS。小时/日汇总与查询在一致事务中工作。
- 管理登录支持明确的“记住登录（仅限可信设备）”选项，默认勾选。
  成功后只写 Observer 自有 localStorage；取消后仅限会话，退出或明确 401 清理。
  共享设备请取消记住并在使用后退出；浏览器存储不是密钥保险库。
- Key 支持不可逆终态删除，清除认证索引但保留历史账目引用；活跃/待记账时返回
  busy。禁用仍可逆，旧 DELETE 仍是撤销，三者不混淆。新随机密钥为 `sk-` 加
  48 位无偏字母数字，内部 ID 不变；明文仅成功后显示一次，仍只存 SHA-256。
- 定价预览和实际报价共用完整身份解析器，支持核实的 `commandcode/`、
  `opencode-go/` 命名空间、明确目录映射与歧义候选。映射只影响未来记账，
  不改 CPA 路由；缺失费率显示 `—`，缺价仍按 $0 并说明原因。
- 请求内容支持关闭/仅安全头/安全头与 JSON 三模式、独立秒级 TTL、单层 gzip、
  读时过期和压缩字节预算下的 FIFO。安全头与正文独立声明状态；
  旧内容格式仍可读，延长 TTL 或队列延迟不会复活过期/清空内容。
- 设置页区分过期清理、确认清空内容和空闲物理整理，显示分类丢弃和维护结果。
  这些操作不改历史费用或额度；关闭采集不等于删除旧内容。
- 增加完整物理视口的原生 200% 缩放截图和实际渲染对比度回归，
  改善小屏容量输入、提示文字及控件边界。

## 升级与兼容性：请先阅读

1. **v0.6/v0.7 的 schema2 库、原 Key、固定费用和累计额度保持兼容**，无需重新发
   Key，保持原 DB 路径。增量增加 `observer_features=1`、小时统计与内容索引；
   仅回填仍存在的明细，不重计旧总额、额度或重新报价。已过期细分无法恢复。
2. **先停流并等待活跃/待记账归零，正常停止 CPA，再备份整个一致数据目录和匹配
   的旧插件二进制**。不要在线普通复制正在写入的 bbolt 文件。宿主用量队列不持久化，
   繁忙热替换无法保证恢复尚未交付的事件。升级后检查健康、旧 Key/费用和采集模式。
3. **回退必须恢复升级前一致备份与对应旧二进制**，不能直接用 v0.7 写新版本已写库。
   旧版不认识新功能/索引标记，也未保证拒绝新库。恢复备份会放弃升级后数据，
   请先保全所需数据并明确接受该代价。v0.6 之前异构旧库仍不迁移。
4. **CPA 原生 Key 与 Observer Key 必须使用不同明文，并只发送一套一致凭据**。
   重复/混合凭据由宿主认证链决定归属，Observer 禁用/删除不能撤销宿主凭据，
   也不能保证把原生流量纳入 Observer 配额。原生调用不进入 Observer 账本。
5. **没有原生 Key 的匿名配置不是透明共存模式**：SDK 安装非独占 provider 后，
   原本匿名返回 200 的目录/生成可能变为 401。本版不通过全局认证成功掩盖限制，
   也不读取宿主秘密或改认证顺序。需要使用原生认证 Key。
6. 物理整理需要空闲和临时磁盘空间，忙时返回 busy；短暂维护期间新受管生成可能收到
   可重试 503。不承诺零停顿或磁盘安全擦除，替换后同步失败会如实报告。

最低 CPA **v8.0.30 / 插件 schema 6**，SDK 仍固定 v8.0.30。
管理 API 保留旧 RFC3339 `[from,to)` 查询和 query-ID 路由；新增
`/requests/view`、`/requests/facets`、`/keys/delete`、`/captures/cleanup`、
`/captures/purge`。新日期视图包含结束日，不与旧范围参数混用。
详细响应、兼容设置写入和 SDK 边界见 [重构说明](reconstruction.md)。

## 验证与构建交付

本轮覆盖 Go unit/race/vet、TypeScript/前端行为、官方 Management Center v1.26.5
多宽度/主题/侧栏/原生缩放、真实 CPA 宿主认证与内容链路、实际 v0.7 writer 的非空
升级和重启、固定 1 万/10 万记录及内容预算负载。Mock 界面验收不代替真实后端验证，
固定本地基准不是生产 SLA；完整验证入口见 README 和重构说明。

界面资源已嵌入动态库，运行不需要 Node/npm/CDN。保留 Linux amd64、
Linux arm64、macOS arm64 三个平台的原生归档；Linux 不适用于 musl/Alpine。
下载后核对 `checksums.txt`；`metadata.json` 记录插件版本、SDK 版本、平台及精确提交。
发布与安装/生产部署是独立操作，本次发布不会自动修改生产配置或数据库。
