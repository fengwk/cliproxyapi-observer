# Observer v1.0.2 发布说明

## 目录价格与展示修复

- models.dev v2 已知的 `cost.web_search` 不再阻断完整文本 Token 价格导入。
  搜索附加费用本身仍未纳入统计，并在候选报价与预检中明确提示；
  音频等非文本费用、缓存存储费用亦保留未计入提示。
- 支持 `multipliers[].factor.text` 数字标量，应用于全部文本 Token 费率，
  完整保留服务等级、日期条件和规则顺序，不将条件价格压平成基础价。
  修复 `google / gemini-3.8-flash` 的文本报价导入。
- `google-vertex / gemini-3.8-flash` 仍包含运行时无法判定的地区条件。
  本版明确提示“缺少上游实际地区”，保持禁止导入该候选价格；
  不假设地区、不删除倍率规则，需手工配置适用价格。
- 无法解析的预检或候选报价不再显示成 `$0` 或“思考同输出”，也不归类为正常零价格。
  已知问题使用可读说明；真正未知、可能改变 Token 价格的字段仍严格拒绝。

## 升级与计费边界

本版沿用 schema3 / `observer_features=3`。从 v1.0.0 或 v1.0.1 升级无需重建数据库；
schema2 及更早版本仍不兼容。升级前请停流备份包含客户端密钥明文的数据目录。

更新插件并重新加载后，请在设置中刷新公共价格目录，以替换旧缓存中的解析结果。
修复后的价格仅用于后续请求，历史账单不重新计价；缺价按零价处理的既有行为不变。
搜索、音频等未纳入的费用不能视为免费，也不代表此处统计等于上游完整账单。
