# Observer v0.9.1 发布说明

## Review 后的修正

- 修复 Key 名称变成可点击按钮后长文本省略失效的问题。长名称恢复实际省略，
  名称按钮、文字和状态保持在名称列内，不再覆盖相邻密钥；完整名称仍可在详情查看。
- 密钥列宽统一由样式表管理，移除 JSX 中重复的内联列宽及原有冲突值。
- 浏览器验收增加名称、按钮和状态的真实列边界检查，并验证长名称实际被省略，
  不以 CSS 声明存在代替渲染效果。
- CI 的官方外壳和真实宿主浏览器环境安装并验证系统中文字体，避免截图中文字
  显示方框而掩盖真实排版。字体仅用于 CI，不嵌入产品或新增运行时 CDN。

## 兼容与升级

这是 v0.9.0 的样式修正补丁，不改认证、模型授权、额度、并发、账本、Key 生命周期
或内容保留规则。CPA 原生凭据与 Observer 继续非独占共存；未纳管入口不向
Observer Key 通用开放。没有 CPA 核心改动，也没有 Go/npm 依赖升级。

沿用 schema2、`observer_features=2` 和原数据库路径，不新增迁移。
**客户端 Key 明文仍保存在管理数据库中**，请妥善管理数据库和一致备份。
旧 hash-only Key 仍可认证但无法还原明文；管理界面查看需要轮换。
从旧版升级或回退的停流备份要求见 [v0.9.0 发布说明](release-notes-v0.9.0.md)。

SDK 仍锁定 CPA v8.0.30，最低插件 schema 6；发行平台仍为 Linux amd64、
Linux arm64、macOS arm64。下载后核对 `checksums.txt` 和归档内 `metadata.json`。
现有发布标签与资产保持不变，本次发布不会部署到生产或修改生产配置、数据库。
