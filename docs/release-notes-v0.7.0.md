# Observer v0.7.0 发布说明

## 本版变化

- 重建管理界面：React 18 + TypeScript + Vite，复用 CPA 的实际颜色、间距、
  表单和弹窗风格。登录前就同步宿主主题，支持暖灰、纯白、深色、跟随系统。
- 嵌入页面使用独立滚动区域，为 CPA 浮动工具栏预留空间；桌面与手机的表单、
  模型选择器、请求详情不再被宿主控件遮挡。
- Key 创建和轮换支持自定义密钥：8–256 个可见 ASCII 字符，不自动去空格。
  重复返回 409，失败的轮换不影响旧凭据；只持久化 SHA-256 哈希。
- UI 的禁用改为可逆操作，保留密钥与历史。轮换、额度重置和故障恢复仍各自独立。
  编辑其他字段不丢失原有效期的纳秒精度。
- 日志提供请求/失败趋势、名称化 Key 筛选、按需加载的脱敏请求头与格式化 JSON。
  使用安全文本渲染，不执行模型名、标签、请求头或正文中的 HTML。
- 设置支持第一次推理前的可用模型基础价格预览、完整目录条目计数和手动覆盖。
  不把 `owned_by` 当作计价 Provider；缺价仍按 $0。预览不生成用量或历史观测。
- 将采集范围明确为“请求头和请求体，不保存响应内容”；存储容量用可读单位显示，
  保存无关设置不损失原始字节精度。通用设置与价格草稿独立保存。
- 轮询在弹窗、编辑、隐藏页面时暂停，401 后清理会话并停止；异步请求可取消。

## 升级与兼容性

- **v0.6.0 → v0.7.0 无需迁移**。继续使用 schema2 数据库、原 Key、历史记录、
  额度、固定费用和故障门禁。默认库仍为 `data/cliproxyapi-observer-v2.db`。
- v0.6.0 之前的旧实现仍不兼容；不要把旧库路径指向本版，参见
  [v0.6.0 说明](release-notes-v0.6.0.md)。
- 升级前备份整个数据目录，安排停流并确认未结算事件已处理。宿主用量队列不持久化，
  繁忙时热替换仍不能保证恢复宿主尚未交付的事件。发布不等于部署。
- 最低 CPA v8.0.30 / 插件 schema 6，SDK 锁定 v8.0.30。真实宿主验收覆盖
  v8.0.30 与 v8.0.33；界面嵌入验收固定官方管理中心 v1.26.5。
- 管理 API 仍使用固定路由和查询 ID，新增认证接口 `POST /prices/preview`，
  静态资源新增 `/theme.js`。原有随机创建/轮换调用保持兼容。

## 构建与交付

界面资源已通过 `go:embed` 编入原生库，运行无需 Node、npm、外部字体或 CDN。
前端开发工具仅在源码构建/测试时使用；Node 22.12+，执行
`npm ci --prefix web && make frontend`。CI 校验已提交的嵌入资源与源码构建一致。

保留 Linux amd64、Linux arm64、macOS arm64 三个平台的原生归档；
Linux 归档不适用于 musl/Alpine。下载后核对 `checksums.txt`，
归档中的 `metadata.json` 提供插件版本、SDK 版本、平台与精确源码提交。

安全边界未放宽：管理接口必须通过 CPA 管理认证，缺价不阻断推理，
费用仍在入库时固定。公开资源页面不包含管理数据，客户端密钥不写入日志或浏览器存储。
