# Observer v1.0.3 发布说明

## 请求日志筛选体验修复

- 请求筛选作为临时查询状态，不再显示“筛选未应用（点击查询或按 Enter 应用）”提示。
- 修改筛选后切换页面，不再弹出“放弃未保存的修改？”确认，也不会因筛选草稿触发浏览器离开保护。
- 查询按钮和 Enter 仍用于应用筛选，查询从第 1 页开始；本版未改成筛选变化即自动查询。
- 编辑筛选期间仍暂停自动刷新，防止刷新覆盖草稿；其他分页、详情和历史区间的刷新保护保持不变。
- 设置和 Key 管理中真正未保存的配置仍保留离开确认与浏览器离开保护。

## 升级边界

本版仅修复前端交互，沿用 schema3 / `observer_features=3`。
从 v1.0.0、v1.0.1 或 v1.0.2 升级无需重建数据库；schema2 及更早版本仍不兼容。
升级前请停流备份包含客户端密钥明文的数据目录。

本版不改变价格匹配、模型路由、认证和 Token 计费规则，也不重新计算历史账单。
更新插件并重新加载后，刷新管理页面以使用新版内嵌前端。
