# Observer v0.6.0 发布说明

## 不兼容变更

这是替换旧只读观测后端的 clean-slate 实现，不是原地升级。最低宿主为
**CPA v8.0.30、插件 schema 6**；SDK v8.0.30。插件 ID 仍为
`cliproxyapi-observer`，名称仍为 Observer。

- 必须使用**新数据库**，默认 `data/cliproxyapi-observer-v2.db`。没有新 schema
  标记的非空库会被拒绝，不迁移、不覆盖、不删除旧库。
- 必须创建**新客户端 Key**。认证能力保持注册期间，插件独占前端认证，不接受宿主
  内置 Key 或旧凭据，内部暂停/存储故障也不回退。宿主停用或卸载插件后，此保护
  不再存在，宿主可恢复自身认证；不要将未加载插件当作安全边界。
- 旧查询、旧配置字段、迁移、查询时重定价全部移除，无兼容 shim。
  管理接口使用静态路径和查询 ID，详见 [README](https://github.com/fengwk/cliproxyapi-observer/blob/v0.6.0/README.md#管理-api)。
- 成本在事件入库时固定，历史不会因修改定价而重算。

请在隔离环境验证并备份原有目录，不要将旧库当作新库。回退需使用对应旧版本及其
保留的数据副本；新 Key、新库不会自动同步回旧版。本交付不执行生产部署或旧库删除。

## 新能力

- 请求日志 / Key 管理 / 设置三页；一次管理登录，默认全部模型，可搜索多选并保留
  不可用的已选 ID。模型来源为管理 nonce `POST /models/token` 后只读
  `GET /v1/models`，不以认证文件列表推断可用模型。
- 专属 Key 哈希存储、一次性显示明文、轮换/撤销、有效期、并发与模型权限。
  5h / 7天 / UTC日历月 / 总额美元额度，独立累计、可选周期重置；零为不限。
  无预扣，已准入的并发执行可能超额。
- int64 micro-USD（1 USD = 1,000,000），每执行汇总后向上取整一次。
  规则 > 手动 > models.dev 自动公共缓存基础价 > 缺价零成本。
  支持完整上下文阈值与 UTC 时段规则，固定单价/来源/金额，不对重试重新报价。
- 默认关闭的敏感采集、有界队列、gzip 与脱敏；读取即过期。
  原始明细默认24h、日汇总默认365天；正文默认1MiB/256MiB，
  安全上限分别为**单条8MiB / 总正文1GiB**，不是整个数据库硬上限。
  日汇总过期不会清空 Key 累计；物理压缩回收空间但不是安全擦除。
- Key 级记账故障阻断及原报价重试。未知用量需管理员显式确认风险后恢复，
  **确认不重建缺失成本**，不清空已有金额或改变限额；重置/轮换不隐式恢复。

## 不能承诺的边界

CPA 的用量队列不持久化，也不保证停机/热替换前排空。可检测的中断会留下阻断标记，
但宿主未交付的事件无法重建，因此不宣称端到端恰好一次。
避免在繁忙期间热更新，先停流并检查健康与未结算状态。缺价记零不是免费承诺，
公共目录价格也不等于供应商最终账单。脱敏不保证发现普通 prompt 中所有秘密。
压缩需要额外磁盘空间，busy 时应稍后重试。

## 验证与发布

正式构建平台保持 Linux amd64、Linux arm64、macOS arm64，采用不可变归档/校验和
发布流程。普通功能合并不触发依赖自动发版策略。归档包含插件版本、SDK 版本、
精确源码提交和平台信息，下载后请核对 `checksums.txt`。

发布验收覆盖：

- 全量 Go unit/vet/race、Node、自动合并/兼容性/打包/发布脚本策略测试；
- CPA v8.0.30 与 v8.0.32 的真实 c-shared 宿主、认证/额度/模型权限、故障恢复与重启；
- 实际 Chrome 的桌面/移动、白色/浅色/深色/自动主题、三页及对话框矩阵，以及两宿主页面验收；
- 纳秒到期时间原样保留、1 GiB 精确边界、字典特殊标识与离线价格缓存回归；
- 三平台原生构建与不可变归档核验。

后续 CI 自动检查基线 v8.0.30 和最新稳定 v8，并保留浏览器报告与截图。
功能验收与故障边界说明不等于生产部署授权；升级仍须先备份并停流维护。
