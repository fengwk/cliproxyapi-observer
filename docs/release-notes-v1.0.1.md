# Observer v1.0.1 发布说明

## 修复

- **紧凑价格设置**：公共价格开关紧邻名称，目录来源标签与有界选择框并排；
  桌面共用一行，窄屏按控件组换行，不再用整行宽度展示一个短选项。
  详细说明收进可展开的 ⓘ，保留公共价仅供参考、手工价优先与缺价按 $0 计费提示。
- **价格预检筛选**：状态选择框与模型搜索框保持同一行，窄屏仅允许模型数量移到下一行。
- **真实账户名称**：请求明细、详情、账户分组和筛选共用 CPA 只读元数据中的账户名称。
  请求表保留“提供商在上、账户在下”，长账户名称单行省略，悬停显示完整名称；
  与账户分组共用省略样式，不再把账户索引显示成账户名称。
- **可读诊断**：无账户名称或 Key 名称时显示明确的中文提示，不用索引或哈希代替。
  精确内部标识仍保留在默认折叠的“技术信息”中；同名账户仍按原始身份独立筛选与分组。

本版包含 v1.0.0 发布后留在 main、尚未进入正式发行包的筛选布局与账户显示修复。
不修改 CPA 核心、认证链、上游路由或历史计费金额。

## 升级

- **从 v1.0.0 / schema3 升级无需重建数据库**；本版不改变 schema 或持久化账户名称。
  升级前仍请停流并备份整个数据目录，数据库与备份包含客户端密钥明文。
- schema2 及更早数据库仍不兼容，不提供自动迁移或就地改写。
  从这些版本升级需备份后使用新数据库并重新创建 Key 与价格配置。
- UI 内嵌在原生插件二进制中。请更新对应平台的插件并重新加载插件，再刷新页面；
  仅刷新页面不会更新旧插件内的 UI。下载后使用 `checksums.txt` 验证 ZIP。
